# World Literature I: Exam #2 Practice Exams

A single-page practice exam site covering Virgil, Ovid, Augustine and Dante.
Five exams use the same 61 questions and get progressively harder, from all multiple choice (Exam 1) to all fill-in-the-blank (Exam 5).

Open `index.html` in a browser. No build step and no dependencies. Attempts and best scores are stored in the browser's localStorage.
